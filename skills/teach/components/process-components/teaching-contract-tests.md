# Teaching Contract Tests

Add tests proportional to the application's authority over learner progress.

- Validate exact curriculum fields, ordering, assessment groups, references, and stale entry hashes.
- Test empty, new, carried-forward, and removed evidence plus complete teacher audits and XP bounds.
- Prove immutable revisions, profile isolation, additive migrations, and completion precedence.
- Prove pending-before-launch, explicit retry, restart recovery, atomic pass transactions, and fail-closed generation.
- Reject student-callable pass, fail, completion, and undo mutations.
- Validate uploaded content rather than filename or browser MIME alone.
- Test one-graph replacement, unsafe SVG rejection, independent checking, and refresh recovery.
- Browser-test mobile layout, modal focus, clipboard files, thumbnails, pagination, renderer failure, MathJax, authentication states, and SSE fallback.

Use small provider fakes and keep one opt-in real authenticated teacher smoke test.
